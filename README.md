# The Moonlit Trail

A small, dependency-free choose-your-own-adventure game played in the terminal. Pick a path through a moonlit forest and cave to discover one of four endings.

## Run

Requires Python 3. Run the game from this directory:

```bash
python3 adventure.py
```

Enter the number beside your choice and press Enter. If you enter something other than a listed number, the game will ask again.

## Example

```text
THE MOONLIT TRAIL
A silver map leads you to the edge of a dark forest.

Which way will you go?
	1. Follow the forest path
	2. Enter the cave
> 2
The cave splits in two. A blue glow shines from one tunnel; a breeze comes from the other.
	1. Follow the blue glow
	2. Follow the breeze
> 1

The glow leads to a crystal lake. Beneath its surface, you discover a sunken library. THE END.
```
